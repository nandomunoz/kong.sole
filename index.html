The cast

Face the Kong

Everything is a single method call. No setup, no build step, and it falls back to plain text when styles are not supported.

01

Status logs

Success, info, warning and error with badges and icons. They use the real console.warn and console.error, so DevTools filters keep working.

02

Banners and text

SVG banners, block letters, gradients, rainbow and neon to make important messages stand out.

03

Images and base64

Draw SVG, base64 strings, data URIs, URLs or Files straight in the console. Best in Chrome and Edge.

04

Characters

A wizard, a cat, a robot and a ghost that say whatever you want in ASCII speech bubbles.

05

Debug helpers

Badges, bars, sparklines, colored JSON, diffs and timers that turn green, yellow or red.

06

Your signature

Leave a message for curious developers who open the console: kong.signature('Ada', 'ada.dev').

Get started

Three lines to roll

Import it from a CDN or copy kong.sole.min.js into your project.

ES module, zero dependencies

// 1. Import
import kong from 'https://cdn.jsdelivr.net/gh/nandovejer/console.cool/kong.sole.min.js';

// 2. Log with style
kong.success('It works!');

// 3. Turn everything off in production
kong.enabled = false;
