What is this?

Face the Kong

Everything is a single method call. No setup, no build step, and it falls back to plain text when styles are not supported.

01

Status logs

Success, info, warning and error with badges and icons. They use the real console.warn and console.error, so DevTools filters keep working.

02

Banners and text

SVG banners, block letters, gradients, rainbow and neon to make important messages stand out.

03

Images and base64

Draw SVG, base64 strings, data URIs, URLs or Files straight in the console. Best in Chrome and Edge.

04

Characters

A wizard, a cat, a robot and a ghost that say whatever you want in ASCII speech bubbles.

05

Debug helpers

Badges, bars, sparklines, colored JSON, diffs and timers that turn green, yellow or red.

06

Your signature

Leave a message for curious developers who open the console: kong.signature('Ada', 'ada.dev').

Get started

Ready in a minute

Install it from npm, load it from a CDN or copy kong.sole.min.js into your project.

ES module, zero dependencies

// 1. Install
npm install kong.sole

// 2. Import (or load it from a CDN, no build step)
import kong from 'kong.sole';
// import kong from 'https://cdn.jsdelivr.net/npm/kong.sole@0.4.0/kong.sole.min.js';

// 3. Log with style
kong.success('It works!');

// 4. Turn everything off in production
kong.enabled = false;

Privacy

We do not collect anything about you. No accounts, no cookies, no analytics, no tracking.

The library
Nonekong.sole makes no network requests, stores nothing and has no telemetry. It only prints to your own console.
Two things happen only when you ask: kong.copy() writes to your clipboard, and kong.image(url) makes the browser fetch the address you gave it.
This website
LocalIt is a static page. The playground runs in your browser and the code you type never leaves it.
1 itemYour theme choice (auto, dark or light) is saved in this browser as kong-theme in localStorage. Clear your site data to remove it.
GoogleThe fonts come from Google Fonts, so Google receives your IP address and browser details when the page loads. The page works without them and falls back to system fonts.
When you install it
npm, jsDelivr and unpkg serve the file and see the request, as any server does. Their own privacy policies apply. To avoid third parties, install from npm and bundle it yourself.
